AI-A1 — صفحة شرح محلية (about.html) بأسلوب داكن واتجاه RTL.
الغرض: تعريف الزائر بالأداة التي تحوّل ردود الذكاء الاصطناعي إلى ملفات وأوامر منفّذة.
تسرد المشكلة (نسخ يدوي، أخطاء بشرية) مقابل الحل (تنسيق ثابت، تطبيق آلي).
تشرح سير العمل في خمس خطوات: طلب → ردّ → قراءة → تطبيق → تحقّق.
تعرض الأشكال الثلاثة للردود: Shape 0 (ok)، Shape A (عمل)، Shape B (طلب معلومات).
تعرّف المفاهيم: ### FILE / ### EDIT / ### DELETE / ## commands / @output / ملفات السياق.
تضمّ مثالًا عمليًا مصغّرًا لإنشاء مكوّن Next.js مع تثبيت حزمة.
تستعرض قواعد الأمان: مسارات نسبية، منع الأوامر المدمّرة، لا تعديل بدون رؤية.
تنتهي بفوتر موسّع فيه 8 أزرار سوشيال (Facebook, X, Instagram, LinkedIn, YouTube, GitHub, TikTok, WhatsApp).
الملف مستقل تمامًا (HTML+CSS+SVG) بلا اعتماد خارجي، ويُفتح محليًا بأمان.
